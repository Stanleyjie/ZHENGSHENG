## 一、模块关系总览

```
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│  销售订单    │ ───▶ │   生产工单   │ ◀─── │   BOM 清单   │
│  客户下单    │ 生成 │   按BOM展开  │ 依据 │  产品构成    │
└─────────────┘      └─────────────┘      └─────────────┘
   明细=成品+数量      明细=各半成品工序      成品→半成品→原料
```

- **BOM 清单**：定义"一个成品/半成品由哪些下级料、经哪道工序、各用多少"构成。是生成工单明细的依据。
- **销售订单**：客户要什么、要多少、什么时候交。是生产的源头需求。
- **生产订单（工单）**：实际下到车间的生产任务。点"生成工单"后按 BOM 展开出各道半成品工序。

## 二、BOM 清单操作

### 入口
菜单：**物料管理 → Bom结构**

页面布局：左侧"生成物料"列表（父料），右侧"工序及构成"。

### 操作步骤

1. **选择父料**
   - 在左侧列表点击要维护 BOM 的**成品或半成品**（原料 `F_MaterialType=0` 不允许配置 BOM，会提示"原料不能有bom构成"）。

2. **选择工序**
   - 右侧"选择工序"下拉会列出该父料**已绑定过的工序**。
   - 点「**新增工序**」弹窗 → 选择工序 → 在下拉里选工序 → 添加子料 → 保存。

3. **维护构成（子料清单）**
   - 下方表格展示"该父料 + 该工序"下的子料，可编辑**数量、备注**。
   - 点「**新建**」弹窗：选物料、填数量、备注 → 加入清单。
   - 勾选行可点「**删除**」移除。
   - 点「**保 存**」：系统对该"父料+工序"的构成**整组覆盖保存**（先删后插）。

4. **查看 BOM 树**
   - 点「**BOM树**」按钮 → 弹出当前选中父料的完整多级结构树（成品 → 半成品 → 半成品 → 原料），便于核对全貌。

### 重要规则
- **多级 BOM 需逐级维护**：成品挂上半成品后，还要点开那个半成品，再去维护它的下一级构成，直到原料为止。
- **循环引用拦截**：保存时自动检测，若子料号是其自身上层料号会提示"BOM构成存在循环引用"，保存失败。
- 示例（当前库数据）：
  ```
  成品 MC_20221021131133
    └─ 半成品02 MC_20221021131103   ×1
        └─ 半成品01 MC_20221021131051  ×1
            ├─ 原材料1 MC_20221021130926  ×1
            └─ 原材料2 MC_20221021131028  ×2
  ```

## 三、销售订单操作

### 入口
菜单：**销售管理 → 销售订单**

### 操作步骤

1. **新增订单**
   - 点「**新增**」→ 弹窗填写：
     - 客户
     - 计划开始时间 ~ 计划结束时间（**结束时间即交期**）
     - 生产天数（默认 6）
     - 总金额
     - 备注/订单说明

2. **添加明细**
   - 明细表格点「**添加**」→ 弹窗：
     - 选**物料**（下拉只显示成品/半成品，`F_MaterialType>0`）
     - 填**单价、数量**
   - 点提交后自动回填物料编号/名称/单位/分类。
   - 明细行可**直接改数量/单价**，可**勾选删除**。

3. **保存**
   - 点「**保存**」→ 订单进入**草稿**状态（未启用）。

4. **启用**
   - 核对无误后点「**启用**」→ 订单生效。
   - 注意：**启用后明细只能改数量/单价，不能再增删明细**；已启用订单不能删除。

5. **生成工单**（关键步骤）
   - 选中一条**已启用、未结案**的订单 → 点「**生成工单**」→ 确认。
   - 系统按**每条明细**生成一个生产工单，并**根据 BOM 自动展开**出各道半成品工序明细。
   - 已生成过工单的明细不会重复生成。

6. **结案**
   - 订单全部交付完成后点「**结案**」，写入实际完成时间。

7. **其他**
   - 「查看」：只读查看订单及明细；「修改」：编辑（受启用状态限制）。

## 四、生产订单（工单）操作

### 入口
菜单：**生产管理 → 工单管理**

### 从销售订单生成后的工单长什么样
- 列表显示：**工单编号**、**来源订单**（销售订单号）、料号、计划数量、计划开始/结束时间、状态。
- 工单明细 = BOM 展开的半成品工序，按**执行顺序**（1、2、3…）排列，例如某成品工单明细：
  ```
  序1  半成品01
  序2  半成品02
  序3  成品
  ```

### 状态流转
| 状态 | 含义 | 何时进入 |
|---|---|---|
| 0 | 等待中 | 生成工单时初始状态 |
| 1 | 执行中 | 开始作业时 |
| 2 | 已完成 | 完工结束（全部明细完成后主单完成） |
| 3 | 已终止 | 预留，暂未启用 |

### 工单执行（作业）
1. 进入「**工单作业**」（WorkOrderRun，工单列表或作业菜单）。
2. 选中要执行的**工单明细** → 点开始：
   - 选择**主设备 + 加载设备**
   - 选择**值班人员**
   - 提交后状态变为"执行中"，写入实际开始时间。
3. 完工后点「**结束**」→ 该明细变为"已完成"并写实际结束时间；全部明细完成后工单整体完成，完成数量回写。

### 其他操作
- 「查看」：查看工单明细与工序流程。
- 「流程图」：查看工序流转图。
- 「修改」：等待中工单可改（可拆分/合并明细）；已执行只能改计划数量。
- 「删除」：等待中可删除。

## 五、完整流程演练（建议首次按此走一遍）

**场景**：客户订 100 台"成品"。

1. **确认 BOM**
   - 物料管理 → Bom结构，选中"成品"，确认 BOM 树完整（成品→半成品→…→原料）。
   - 若缺半成品构成，先逐级维护好。

2. **录销售订单**
   - 销售管理 → 销售订单 → 新增：
     - 客户：某某公司
     - 计划时间：开始今天 / 结束交期日
     - 明细：成品，数量 100
   - 保存 → 启用。

3. **生成工单**
   - 选中该订单 → 点「生成工单」。
   - 到 生产管理 → 工单管理 确认出现新工单，来源订单 = 该销售订单号，明细 = BOM 展开的各半成品工序。

4. **执行作业**
   - 工单作业里选设备、人员开始作业，完成后结束。

## 六、常见问题与注意事项

| 问题 | 原因/处理 |
|---|---|
| 生成工单提示"请先启用销售订单" | 订单还是草稿，先点「启用」。 |
| 生成工单提示"销售订单已结案" | 订单已结案，不能重复生成。 |
| 生成工单提示"销售订单没有明细" | 明细为空，需先添加明细。 |
| BOM 保存提示"原料不能有bom构成" | 父料是原料（分类=0），原料只能当子料。 |
| BOM 保存提示"BOM构成存在循环引用" | 子料反过来成了自己的上层料号，检查构成。 |
| 工单页打不开/数据 404 | 代码未更新，需重新发布/回收应用池。 |
| 改了菜单/数据不刷新 | 清缓存：admin 登录调「清理缓存」，或清 Redis。 |
| 明细里选不到某个料 | 销售订单明细只显示成品/半成品（`F_MaterialType>0`）。 |

> 备注：多级 BOM 无树形维护（需逐级点开），但可用「BOM树」按钮整体核对；替代料、BOM 版本、Excel 导入等为后续可选增强。
